# Deviations from the pre-specified analysis plan

1. **23 September 2026, before results.** P1 gene set added: `cheon2014_collagen` (10 genes; Cheon et al. 2014, Clin Cancer Res 20(3):711-723, doi 10.1158/1078-0432.CCR-13-1256). The Cheon signature named in plan v1.0 was not previously in the project gene-set JSON.
2. **23 September 2026, before results.** P2 gene set changed from `resistance_up_core` to `resistance_up_intrinsic` (14 genes: `resistance_up_core` without FOS, JUN, NR4A1, COL11A1, LOX, FABP4, IL6, STAT3, STAB1), to avoid overlap with the stress positive control (`stress_IEG_state_GSE165897`) and with stromal genes.
3. **23 September 2026, before results.** Gene sets with fewer than 5 genes (`matrix_CAF`, `sensitivity_up`, `partial_EMT_Xu2022`) moved from set-level testing to gene-level reporting. The 5-gene minimum is unchanged.
4. **23 September 2026, before results.** liana-py (rank_aggregate by sample) chosen as the cell-cell communication tool for secondary analysis 7.
5. **D1 — Decided 28 October 2026; committed 29 October 2026, before any resistant-versus-sensitive, composition, communication or TCGA analysis was run.** Clarification, not a deviation. The Stage 01 pipeline check in `config.yml` (ARI >= 0.70 against author labels) failed: ARI 0.643, precision 0.969, recall 0.639. This does not change the analysis plan, which already specifies the author EOC annotation for primary analyses (ANALYSIS_PLAN.md section 2). For secondary analysis 2, "inferCNV-confirmed malignant cells" means cells called malignant by both our inferCNV and the authors.
6. **D2 — Decided 28 October 2026; committed 29 October 2026, before any resistant-versus-sensitive, composition, communication or TCGA analysis was run.** CRS grouping. Pre-specified: CRS 3 = responder. Observed: one CRS 3 patient (EOC443), giving 1 vs 10, below the minimum of 3 per group. Change: CRS 1 (poor response) vs CRS 2-3. Malignant cells: 3 vs 8. CAFs: EOC733 (poor_response) and EOC227 (response) each have fewer than 20 treatment-naive CAFs, giving 2 vs 7, so the CAF CRS contrast is reported as not estimable. The PFI-by-CRS cross-tabulation is reported descriptively.
7. **D3 — Decided 28 October 2026; committed 29 October 2026, before any resistant-versus-sensitive, composition, communication or TCGA analysis was run.** Scope. liana-py cell-cell communication becomes secondary and exploratory: run only if the primary tests and the TCGA validation are complete by 24 Nov 2026, otherwise reported as future work. GSE300897 is not analysed and is named as future work.
8. **D4 — Decided 28 October 2026; committed 29 October 2026, before any resistant-versus-sensitive, composition, communication or TCGA analysis was run.** Freezing. Six of 22 samples were frozen before scRNA-seq. Freezing can only bias a paired before-after change when it differs within a pair (EOC1005: post-NACT only; EOC3: treatment-naive only). Sensitivity analysis: repeat the stress-module positive control excluding EOC1005 and EOC3.
9. **D5 — Decided 28 October 2026; committed 29 October 2026, before any resistant-versus-sensitive, composition, communication or TCGA analysis was run.** Sampling site. (a) Six of 11 patients were sampled at different sites before and after NACT. Sensitivity analysis: repeat before-after analyses in the five site-matched patients (EOC153, EOC227, EOC372, EOC443, EOC540) as a direction check only. (b) At baseline, 5/7 resistant but 1/4 sensitive patients were sampled from peritoneum. Sensitivity analysis: repeat P1 and P2 with baseline site (peritoneum vs other) as a covariate.
10. **D6 — Decided and committed 29 October 2026, before any resistant-versus-sensitive, composition, communication or TCGA analysis was run.** Composition (plan 6.6). The analysed object (`data/sce_clustered.rds`) excludes 9,660 cells whose author subtypes fall outside the pipeline's cell-type vocabulary (B cells, NK, mast, DC-1, DC-2, pDC, plasma, ILC, mesothelial). Proportions computed from it would be distorted, so the composition analysis uses all 51,786 cells in `GSE165897_cellInfo_HGSOC.tsv.gz`, with author labels at this level: malignant (all EOC clusters), CAF-1, CAF-2, CAF-3, mesothelial, endothelial, macrophages, T cells, B cells, plasma cells, NK, mast cells, DC-1, DC-2, pDC, ILC. Test: `speckle::propeller` (logit transform), treatment-naive samples, PFI groups. P1 and P2 are unaffected, as no malignant or fibroblast cells were excluded.
